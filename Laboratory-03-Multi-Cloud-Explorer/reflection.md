After completing Mission 3, the cloud platform that impressed me the most is Amazon Web Services (AWS). I was impressed by the wide variety of services AWS provides for computing, storage, databases, networking, security, and application development. I also learned that AWS can support both small startups and large organizations because its resources can be scaled according to business needs.

AWS, Microsoft Azure, and Google Cloud Platform (GCP) have many similarities. All three provide cloud computing services such as virtual machines, object storage, databases, networking, identity management, and security. They also allow organizations to scale their resources, deploy applications globally, and manage infrastructure through web-based management consoles. However, each provider has different strengths that can make one more suitable than another for a specific organization.

Business requirements have an important influence on cloud platform selection. Factors such as budget, existing technology, performance requirements, scalability, security, location, and the type of application must be considered before choosing a provider. For example, Azure can be a strong choice for an organization that already uses Microsoft technologies, while GCP can be suitable for AI and Machine Learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned to analyze the client's actual requirements and match them with the services and strengths of each provider. This activity helped me develop better decision-making and cloud infrastructure analysis skills.

Cloud computing has become a part of my everyday life because many of the applications I use rely on cloud services. Three cloud services that I regularly use are **Google Drive**, **Facebook Messenger**, and **GCash**. These platforms allow me to store files, communicate with others, and perform financial transactions conveniently using the internet.
Google Drive is an example of **Software as a Service (SaaS)** because I use it directly through a web browser or mobile app without managing the underlying infrastructure. Its deployment model is **Public Cloud** since it is available to anyone with a Google account. Facebook Messenger is also **SaaS** because it provides messaging services over the internet, while Meta manages the servers and software. It is classified as a **Public Cloud** service because it is accessible to millions of users worldwide. GCash is another **SaaS** application that allows users to send money, pay bills, and purchase products online. Its deployment model is also **Public Cloud** because it serves the general public through cloud-based infrastructure.
Version control is essential when working with cloud infrastructure because it keeps a complete history of changes made to files, scripts, and configurations. This makes it easier to identify mistakes, restore previous versions, and understand who made specific changes. Without version control, managing cloud resources can become confusing, especially when multiple people are working on the same project.
Git and GitHub make collaboration more organized and efficient. Git tracks every modification made to a project, while GitHub provides a shared online repository where team members can work together. Features such as branches, pull requests, and code reviews allow developers to test changes safely before merging them into the main project. These tools help reduce conflicts, prevent accidental errors, and ensure that cloud-based projects remain reliable, secure, and well-documented throughout the development process.
